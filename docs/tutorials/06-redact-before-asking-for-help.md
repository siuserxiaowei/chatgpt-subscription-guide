# 求助前只收集脱敏信息

本页由 PayForGPT 维护，和商家有商业关联。它不是 OpenAI 官方文档，也不是独立测评。购买步骤见 [从选商品到查单的充值操作](../chatgpt-recharge-guide.md)。维护关系见 [谁在维护](../../README.md#谁在维护)。

这页帮你在问支持之前，准备一份别人看得懂、又不含登录凭据的记录。

## 这篇适合什么情况

你已经按前面的教程核对过，仍然不知道订阅在哪个账号，或原订单是什么状态。

页面有错误提示，你需要把提示原文发给支持。

你准备把截图发到聊天、邮件、工单，或本仓库的公开讨论。

这页不收集你的资料。请不要把真实订单或账号材料贴到本仓库。

## 两套求助不要混用

官方订阅的问题，问 OpenAI 支持。帮助页写的入口是帮助中心里的支持。本次没有单独核实聊天窗口在每个地区是否都显示，所以这里不描述按钮颜色或位置。找不到入口时，停在帮助中心页面里继续找，不要改把密码交给商家。

PayForGPT 订单的交付、重复付款和退款边界，问商家。联系方式以你打开 [PayForGPT 退款与质保政策](https://payforgpt.com/refund) 时页面上写的为准。本篇不另抄一份可能过期的微信号或邮箱。

Apple 订阅的退款，2026-11-07 读到的帮助页要求向 Apple 提出。Google Play 或 chatgpt.com 的退款，帮助页要求联系 OpenAI 支持，并登录与扣款相关的 ChatGPT 账号。不要把 Apple 收据只发给 PayForGPT，就当成已经向 Apple 申请退款。也不要把商家订单号只发给 OpenAI，就当成已经查询了商家订单。

两套材料分开写。每一份都写明收款方。

## 按这个顺序核对

先确认你已经停止了第二次付款，并且试过 [付款后没有跳回时，先查原订单](05-check-original-order.md)。还没查原订单就求助，支持通常缺少「原记录是什么」这一项。

### 可以写下来的内容

官方帮助页允许并需要的内容，用你自己的话整理成下面几行。

试过哪些 ChatGPT 账号。邮箱写成脱敏形式。登录方式只写类型，例如邮箱、Google、Microsoft 或 Apple。

购买平台是 Apple App Store、Google Play、chatgpt.com，还是 PayForGPT。不确定就写「还没分清」，不要猜一个。

错误提示的原文。只抄屏幕上的那一句。

你已经做过的步骤，包括没有再付第二次。

查看原来的 ChatGPT 账号之后，计划名称是什么。

如果已经扣款：付款日期、金额可以只写你认得出的范围、交易尾号或商店订单号。PayForGPT 订单可以提供订单号。Google Play 可以提供帮助页提到的订单历史里的订单号。

你希望对方做的事，用一个动词说清，例如查询原订单、取消尚未交付的订单，或协助看订阅在哪个账号。不要同时写互相矛盾的要求。

### 不要发送的内容

下面这些不要出现在文字、截图、文件名或压缩包里。

密码，包括 ChatGPT 密码、邮箱密码和支付密码。

一次性验证码。

API token、access token、session、cookie。

PayForGPT 查单密码。它只填在 [PayForGPT 订单查询页](https://payforgpt.com/order) 的密码框。退款页写明不要发给客服或第三方。

完整卡密，或还没遮挡的兑换码。

完整银行卡号、完整身份证件、带完整二维码或条码的支付凭证原图。

有人说必须收到这些才可以查询时，停止发送，并回到订单查询页或官方帮助页上的支持入口。本篇不提供用 token 或 session 代替登录的做法。

截图发出去之前，遮住完整邮箱、完整卡号和任何一长串密钥。只保留错误原文、时间、计划名称和交易尾号。

### 一份脱敏例子

下面每一行都是编出来的例子，不是真实账号，也不能拿去查询。

```text
收款方：还没分清是 chatgpt.com 还是 Apple
当前看到的账号：a***@example.com，登录方式是邮箱
计划名称：屏幕上仍是 Free
时间：2026-11-07 下午，时区 Asia/Shanghai
错误原文：只抄你屏幕上的那一句
已做：没有第二次付款。iPhone 订阅列表里还没找到 ChatGPT
希望：先帮我确认原购买在哪个账号，不要让我再付
没有附带：密码、验证码、session、cookie、token、查单密码、完整卡密
```

你的真实记录放在私下的笔记或对应的支持表单里。不要把真实记录贴到本仓库。

商家订单可以把例子里的收款方写成 PayForGPT，并加上订单号。仍然不要加查单密码。原下单邮箱按同样方式脱敏。需要在订单查询页登录查询时，在那个页面输入，而不是写进求助信。

## 这时停下来

你还没写明收款方，材料会送到错误的一边。

记录里已经出现密码、验证码、token、session、cookie、查单密码或完整卡密。先删掉这些，再考虑发送。

有人要求你把这些凭据上传到表单、网盘或仓库「才能人工查看」。不要上传。

你想让对方代为绕过地区限制、用量上限或账号限制。本仓库不提供这些做法，官方帮助页也写明用量上限不能靠一项设置绕过。

## 下一步

官方支持可以参考帮助页列出的项目。原文在 [OpenAI 的订阅访问和账号变更说明](https://help.openai.com/en/articles/20001056-troubleshooting-chatgpt-subscription-access-and-account-changes)。

商家要哪些订单材料、不要哪些凭据，以 [PayForGPT 退款与质保政策](https://payforgpt.com/refund) 当次页面为准。该页还写了可以提供的订单号、付款时间与金额、交易尾号或 txid，以及脱敏截图。

如果核对后发现是两个官方渠道各有一笔订阅，回到 [网页、App Store 和 Google Play 要分开查重](03-separate-web-apple-google.md)。取消和退款不是同一步。
