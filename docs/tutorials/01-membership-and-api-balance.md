# 会员付款和 API 额度不是同一笔账

本页由 PayForGPT 维护，和商家有商业关联。它不是 OpenAI 官方文档，也不是独立测评。完整说明见 [谁在维护](../../README.md#谁在维护)。

这页帮你确认：付 ChatGPT 会员，和给 API 平台准备额度，是不是同一件事。

## 这篇适合什么情况

你准备购买 Plus、Pro，或商家商品页上的月卡，但实际要付的是程序调用的 API 费用。

你已经有会员，API 账单仍然显示没有额度，或扣的是另一套费用。

商品说明、聊天记录或教程把「会员」「Credits」「API 余额」当成同一个词。

这页不帮你比较模型单价，也不提供 API 价目。

## 先分清两套账单

2026-11-07 读到的 OpenAI 计费帮助页把两套账分开写。

ChatGPT 订阅是一套。API 平台是另一套。API 额度，包括促销额度，记在某个 API 组织名下。它和 ChatGPT 订阅分开，也和 ChatGPT 产品里面使用的额度余额分开。

同一页还写：符合条件的订阅，可能给关联的 API 组织促销额度，但两套账单仍然分开。那页指向的权益说明，本次没有打开。所以这里不写谁符合条件，也不写有多少额度。

因此，会员页面显示 Plus 或 Pro，不能用来证明 API 账户里已经有可用额度。要看 API 自己的账单。

PayForGPT 这边也不是 API 充值入口。2026-11-07 直接读到的退款页写明，在售是 ChatGPT Plus、ChatGPT 5x、ChatGPT 20x 月卡类代充，不售 Credits。该页的质保范围不覆盖读者对 API 余额的期望。订单查询页写明，订单状态不是官方 Credits 余额；订单完成不等于 API 余额增加。

5x 和 20x 是商家商品名，不是 API 额度包的名字。怎样和官方档位名区分，见 [按需求区分 Plus 和 Pro](04-choose-plus-and-pro.md)。

## 按这个顺序核对

1. 用一句话写下你要付费的事情。是在 ChatGPT 对话里使用会员功能，还是在 API 平台按调用付费。写不出来就先停，不要付款。
2. 如果是对话会员，用浏览器登录那个 ChatGPT 账号。打开设置，进入帮助页称为 Billing 的账单入口。帮助页说，Free、Go、Plus、Pro 都从这里看网页账单。
3. 如果看不到付款或账单控件，不要换一个 ChatGPT 账号再试。帮助页的做法是换一个浏览器，仍然登录同一个账号，然后再开账单。
4. 如果是 API，打开 API 账户自己的账单。帮助页说，开始付费使用前，要在 API 账单里单独添加付款方式。用量和 ChatGPT 订阅分开计。该页说，API 组织的所有者才能查看账单详情。你不是所有者时，先停下来问组织管理员，不要自己另买一个会员来代替。
5. 对照两个页面上的产品名称。一边是 ChatGPT 的计划名，一边是 API 组织的额度或账单。名称不同，就按两笔处理。
6. 如果有人建议用 PayForGPT 的 Plus、5x 或 20x 去给 API 充值，停在购买前。退款页写的是会员月卡，不是 Credits，也不是 API 余额。

界面如果是中文，账单入口的文字可能不是 Billing。找不到和「账单」或「付款」对应的项目时，停下来，不要为了进入下一页而付款。

## 这时停下来

两套页面你只能打开一套，另一套还不知道登录的是谁。

商品说明没有写清交付的是 ChatGPT 会员，还是 API 额度。

你需要的是帮助页提到的促销 API 额度，但这篇没有打开那份资格说明，不能替你判断有没有、有多少。

你已经扣款，却不确定扣的是会员还是 API。这时不要再付。转到 [付款后没有跳回时，先查原订单](05-check-original-order.md)。

## 下一步

还没付款，并且确认要的是会员：先做 [付款前核对目标账号和已有订阅](02-check-account-before-paying.md)，再看 [按需求区分 Plus 和 Pro](04-choose-plus-and-pro.md)。

确认要的是 API：留在 API 账单和 OpenAI 的 API 价格页。本篇不转述价格。PayForGPT 的三档月卡不解决这个需求。

官方原文见 [OpenAI 的 ChatGPT 与 API 计费说明](https://help.openai.com/en/articles/9039756-managing-billing-for-chatgpt-and-the-api-platform)。

商家商品范围见 [PayForGPT 退款与质保政策](https://payforgpt.com/refund)。
