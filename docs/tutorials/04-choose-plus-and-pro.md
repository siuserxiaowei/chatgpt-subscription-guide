# 按需求区分 Plus 和 Pro，不要只看商品名

本页由 PayForGPT 维护，和商家有商业关联。它不是 OpenAI 官方文档，也不是独立测评。完整说明见 [谁在维护](../../README.md#谁在维护)。

这页帮你按自己的使用瓶颈选择方向，并防止把官方档位名和商家商品名当成同一个按钮。

## 这篇适合什么情况

你已经确定要买的是 ChatGPT 会员，不是 API 额度。如果还没确定，先读 [会员付款和 API 额度不是同一笔账](01-membership-and-api-balance.md)。

你在 Plus、Pro，以及商家页面上的 5x、20x 之间犹豫。

你看到更高一档就准备直接购买，但说不出当前计划卡在哪里。

你想把商品名里的数字理解成永久的用量倍数。

## 官方档位名和商家商品名

两边用的名字不一样。本篇不把它们合并成一张价格表，也不抄用量数字。

### 官方帮助页使用的名称

2026-11-07 另两次读取到的 OpenAI 帮助页《About ChatGPT Pro tiers》列出三个按月的 Pro 计划，名称是 Pro 100、Pro 200 和 Pro 500。

该页有一张美元价格表。价格会变，本仓库不复制这张表。你要看金额时，打开这篇帮助页，并看你自己结账页上的币种、税额和应付金额。

该页在这次阅读中写明：Ultrafast 只包含在 Pro 500，不包含在 Pro 100 和 Pro 200。它同时写明，更大的包含用量不保证完成的任务数量也按同样比例增加。具体倍数、周上限和积分费率，本篇不抄。那些数字以帮助页和你账号里的用量说明为准。

该页还写：这次 Pro 调整没有改变 Plus 的用量。这是那一版帮助页的话。以后 Plus 有没有变化，要再看帮助页，不要靠本篇记忆。

计费帮助页另外使用了 Free、Go、Plus、Pro，以及 Business、Enterprise、Edu。Go 和这些工作区计划不是 PayForGPT 退款页列出的在售月卡。不要把 Go 或 Business 和 5x、20x 当成同一个名称。

该页写明 Pro 按月计费，没有年付，也不能一次预付多个月。如果结账页显示的周期和这句话不同，以结账页为准，并停下来核对，不要用旧文章压过结账页。

变更已有 Pro 时，帮助页写的入口是设置里的 My Plan。这和 Billing 不是同一个词。看不到 My Plan 时，不要连续点购买来寻找它。

达到某个模型的上限，帮助页说不等于订阅结束，也不等于账号被限制。支持人员不能把用量上限重置掉。本篇不写绕过上限的办法。

### 商家商品使用的名称

2026-11-07 直接读到的 PayForGPT 退款页写明，在售月卡是 ChatGPT Plus、ChatGPT 5x、ChatGPT 20x。该页自标更新时间是 2026-11-03（Asia/Shanghai）。

在退款页里，5x 被解释为对应官方 Pro 100 档位口径的月卡，20x 被解释为对应官方 Pro 200 档位口径的月卡。同一页要求：档位名称以商品页为准，不要把商品名当成永远的固定倍数，额度以你账号里显示的为准。

同一天直接读到的首页商品卡，用的是另一组词：5x 写成对照官方 Pro 档，20x 写成比 5x 更高用量。这次读到的首页正文没有使用 Pro 100 这几个字。

所以 5x 不是官方按钮名，20x 也不是。官方帮助页用的是 Pro 100、Pro 200、Pro 500。商家两页之间的措辞也不完全相同。付款前只认你即将购买的那张商品说明里写出的实际计划名称。

2026-11-07 直接读到的商家变更说明页写明：本站只售 Plus、5x、20x；Pro 500 在该页是官方信息介绍，不是本站商品；商品名不保证固定任务倍数。以后卖不卖某一档，以下单页为准。

首页还有企业采购和 Business 选型文字。退款页的在售列表没有 Business。本篇不把那段文字写成已经核实的在售商品。需要官方 Business 时，走工作区自己的账单。需要向商家买之前，先在当时的商品页看到明确的商品名。

## 按这个顺序核对

1. 写下你现在的计划名称，以及你实际被挡住的事情。例如某个模型不可用、用量提示已到上限，或工作必须用到帮助页所说的仅某一档才有的能力。只写「想要更高」不算完成这一步。
2. 打开 [OpenAI 的 Pro 档位说明](https://help.openai.com/en/articles/9793128-about-chatgpt-pro-tiers)，只核对计划名称和你关心的能力是否被该页提到。不要把本篇当成价格或倍数的副本。
3. 打开你自己的结账页或 My Plan。抄下三个可见项：计划的完整名称、计费周期、这次应付的币种和金额。金额留在你自己的记录里，不要发到公开页面。
4. 把结账页上的名称和帮助页上的名称对一下。对不上，或结账页没有写出完整名称，就停。
5. 如果看的是 PayForGPT 商品，再对一次商品名。你要的官方名称如果是 Pro 500，而商品列表只有 Plus、5x、20x，不要把 20x 当成 Pro 500。你要的名称如果是 Pro 100 或 Pro 200，不要只因为商品叫 5x 或 20x 就认为已经对齐。打开该商品说明，看它写出的实际计划。没写清楚就不要付款。
6. 付款前还要确认账号和旧订阅。步骤在 [付款前核对目标账号和已有订阅](02-check-account-before-paying.md) 和 [网页、App Store 和 Google Play 要分开查重](03-separate-web-apple-google.md)。换档不会自动取消另一条渠道上的旧订阅。

官方帮助页说，更换 Pro 时使用你现有的 ChatGPT 账号。不要为了换档新注册一个账号，除非你明确要给另一个账号单独买一份，并且接受订阅不能合并。

## 这时停下来

说不出当前瓶颈，只是因为档位更高。

结账页、帮助页和商品说明里的名称对不上。

你需要的是 API 额度、工作区账单，或帮助页没有写进这三档的能力。

商品把数字写成倍数，但页面又说这不代表固定倍数。以页面后一句为准，不要自己算一个额度。

有人用旧价格或旧倍数催你立刻付款。本仓库不保存这些数字。打开当次页面再决定。

## 下一步

名称和账号都核对过，再付款。付完没有回到预期页面时，按 [付款后没有跳回时，先查原订单](05-check-original-order.md)。

商家商品名和官方档位口径的页面见 [PayForGPT 关于 Pro 变更应付项目的说明](https://payforgpt.com/ai-subscriptions/chatgpt-pro-change-billing-cycle)。这页会提到价格和倍数。那些数字以你打开时的官方帮助页和结账页为准，不要引用本仓库里没有抄录的旧数字。

售后边界仍以 [PayForGPT 退款与质保政策](https://payforgpt.com/refund) 为准。买错档并且已经兑换成功时，该页写明一般不做无理由退款。还没交付时按该页处理，不要先付第二次。
