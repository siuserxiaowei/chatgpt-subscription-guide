## 1. 为什么 OpenAI 官网英文 Invoice 常被国内财务退单？

OpenAI 官网或海外应用商店直接扣款生成的是境外英文 `Invoice / Receipt`，没有中国税务机关监制章、无国内统一社会信用代码与增值税税率栏。除少数具备跨境付汇及代扣代缴申报流程的外企或涉外主体外，多数国内公司、高校科研项目与公务卡报销要求提供**境内有限公司开具的增值税普通发票或增值税专用发票**。

> 注意：由 PayForGPT 关联国内有限公司开具的发票属于境内第三方技术/软件服务发票，**不是 OpenAI 官方发票**。报销入账与专票抵扣条件以贵单位财务制度为准。

## 3. 可开具类目与报销归档五件套

按真实服务交易开具与软件、AI 及技术服务相符的合规类目（不套开餐饮、办公用品等无关类目），常见可选项目包括：
- `*信息技术服务*人工智能应用软件开发`
- `*信息技术服务*技术服务 / 信息技术咨询服务`
- `*软件服务*软件开发 / 计算机系统服务`
- `*现代服务*数据处理和存储支持服务`

建议报销归档保留以下五项材料：
1. **采购需求与含税报价确认记录**（写明 Plus / 5x / 20x 档位、套数与周期）
2. **国内采购合同与资质附件**（电子签或盖章 PDF 扫描件；如需可附营业执照、开票资料）
3. **同一笔交易的付款凭证**（公对公银行电子回单，或支付宝/公务卡绑定支付记录 + `/order` 订单记录）
4. **国内增值税普票或专票版式文件**（核对抬头、纳税人识别号、项目名称与金额）
5. **使用者本人账号脱敏验收截图**（每人登录各自本人账号确认订阅方案与到期周期，切勿附带密码或会话信息）
